    internet, or issuance never completes.
{{- if not .Values.tls.acme.persistence.enabled }}

  ! `tls.acme.persistence` is off: the certificate cache is an emptyDir, so
    every restart re-orders. Let's Encrypt allows 5 duplicate certificates a
    week. Turn persistence on before this serves anything real.
{{- end }}
{{- if gt (int .Values.replicaCount) 1 }}

  ! replicaCount is {{ .Values.replicaCount }} and each replica runs its own ACME client for the
    same name -- they race, and spend that duplicate-certificate limit between
    them. For more than one replica, issue centrally with cert-manager and set
    `tls.secretName` instead.
{{- end }}
{{- else if not .Values.tls.secretName }}

  ! No `tls.secretName`: the gateway is serving a throwaway self-signed cert.
    Point it at a kubernetes.io/tls secret (cert-manager writes one); with
    `reload.tls` it rotates in place, or set `tls.acme.enabled` to have the
    gateway obtain its own from Let's Encrypt.
{{- end }}
